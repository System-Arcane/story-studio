# STory — 결정 사항과 프론트엔드 목업

## 서비스
대학 전시 부스를 방문한 학생·교수가 QR로 접속하여 음식·음료 사진을 올리고, 긍정적인 공감을 만드는 서사가 담긴 세로형 30초 광고를 만드는 모바일 반응형 웹. 우선 상품은 커피·빵·과자. 교수 시연은 인터뷰 당시 4일 후, 최종 전시는 11월. 초기 예산 150,000원 및 보유 Higgsfield Ultra 크레딧 활용 검토.

## 사용자 경험
사진 업로드 → 상품명·종류·특징 한 줄 확인/수정 → 상품 등장 방식 선택(처음부터 주인공 / 마지막에 반전·해결책) → 유머·감동·행복 이야기 3개 중 선택 → 자동 제작 → 결과 확인·저장·공유. 이야기 카드는 제목, 줄거리, 마지막에 기억되는 상품의 인상을 표시한다. 기존 작품은 이야기 구조를 참고하여 상품만의 새로운 서사로 제작한다.

## 향후 실제 생성 파이프라인 (이번 구현에서 제외)
GPT Image 2 상품 배경 정리·prop 레퍼런스 시트 → 서사 창작/선택 → 필요한 캐릭터·공간 레퍼런스 생성 → 공식 가이드 기반 프롬프트와 복수 이미지를 Seedance 2.5 omni-reference 모드에 전달 → 30초 AI 영상 → 한국어 자막·배경음악·내레이션 및 결과 회수. 시연부터 실제 AI 영상 장면과 전 과정 자동화가 목표이며 수동 운영자 제작/템플릿 전용 서비스로 대체하지 않는다. 웹서버에서 MCP를 상시 호출하는 인증/실행 방식과 구독 크레딧 적용은 검증 필요. 현재는 사용자의 최신 요청에 따라 프론트엔드만 구현한다.

## 운영
최종 전시 하루 30명 × 7일, 일회용 코드당 영상 1개. 시연 목업에는 코드 단계 없음. 같은 브라우저 결과 재확인·개인 결과 링크 우선, 문자·이메일 추후. 통계는 관리자 전용. 영상에 STory 워터마크나 부스 안내를 별도로 삽입하지 않는다.

## 디자인
흰색·하늘색·회색, 레드 포인트. 서울과학기술대학교의 색감에 어울리되 학교 홈페이지 배치를 모방하지 않는 광고 제작 스튜디오. 타이포그래피, 넓은 여백, 상품 중심 시각 구성.

## 구현된 목업과 한계
- Next.js App Router / TypeScript / CSS / lucide-react.
- 실제 로컬 파일 업로드 및 이미지 미리보기. JPG/PNG/WEBP, 10MB 제한.
- 수정 가능한 상품 정보, 등장 방식, 3가지 이야기 카드, 진행 시뮬레이션.
- 원본 미리보기만 제공. 배경 제거/분석은 하지 않는다.
- 결과 미리보기는 CSS 기반 무음 30초 스토리보드이며 영상 파일이 아니다. 실제 영상 다운로드 없음.
- localStorage에 마지막 결과 저장. /#result는 동일 브라우저 데이터 복원용이며 다른 기기 공유는 지원하지 않는다.
- /admin은 예시 통계·로컬 토글만 있는 개발 목업. 인증/접근 제어 없음. 실제 관리자 기능으로 배포하면 안 된다. 공개 UI에는 링크 없음.
- API 라우트, 백엔드, 모델 호출, 과금, 업로드 서버, 실제 통계 수집 없음.
