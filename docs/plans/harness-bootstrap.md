# 하네스 초기 설정

## 목표
제품 UI/백엔드를 변경하지 않고, 서브 에이전트가 읽을 문서 지도와 협업 계약 및 실행 가능한 검증 진입점을 추가한다.

## 담당
- 메인: AGENTS.md, ARCHITECTURE.md, docs/HARNESS.md, docs/QUALITY.md, 검증 스크립트와 package.json.
- harness_review: 기존 코드·결정 사항의 읽기 전용 검토. 파일 수정 없음.

## 진행
- 공식 글 확인 및 기존 구조 점검 완료.
- 문서 지도, 파일 소유권, 피드백 루프와 품질 기준 작성 완료.
- 문서 링크 검사 및 verify 명령 추가.
- `npm run verify` 통과: 문서 7개 링크 검사, 프로덕션 빌드, 타입 검사 성공.
- 읽기 전용 서브 에이전트 검토 완료: 저장 스키마, 용량 초과/이전 결과 복원, 상태 초기화, 접근성 문제를 QUALITY 기술 부채에 기록.
- 이번 작업은 문서·검증 명령 변경만 포함하므로 UI 브라우저 검증을 재실행하지 않음. 위 부채를 수정했다고 주장하지 않음.
- 하네스 초기 설정 완료. 다음 기능 작업에서 관련 부채를 우선 검토한다.

## 결정
기존 Next.js 자동 지침 유지. 커스텀 에이전트 TOML·예약 실행·자동 병합·백엔드·AI 호출은 이번 범위에서 제외. 현 세션의 위임 도구와 프로젝트 지침으로 협업한다.
