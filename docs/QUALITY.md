# 품질 기준과 검증 상태

## 완료 기준
- `npm run verify` 성공. 문서 링크, 프로덕션 빌드, TypeScript 확인.
- UI 변경 시 관련 화면에서 모바일 390px 및 데스크톱 1280px 기준 가로 넘침·텍스트 잘림·키보드 포커스를 확인. 도구 제한 시 미확인 항목으로 보고.
- 상태 변경 시 해당 흐름을 실제 브라우저에서 재현. 자동 검사 성공을 브라우저 동작 확인으로 대신하지 않는다.
- 실제 AI 영상/인증/공유 서버가 없는 상태를 정확히 표시한다.

## 사용자 흐름 확인 항목
1. 유효 이미지 미리보기, 형식/크기 오류, 필수 입력 누락.
2. 유머/감동/행복과 상품 등장 방식 선택이 결과에 반영됨.
3. 제작 시뮬레이션 완료, 중간 이탈, 재진입 시 진행 상태.
4. 결과 저장/새로고침 복원, 손상 데이터, 저장 공간 부족, 클립보드 불가 상황.
5. 목업 관리자 링크는 방문객 메뉴에 없음. /admin 직접 접근은 인증이 없는 예시 화면임.

## 알려진 기술 부채
- `app/page.tsx`와 전역 CSS에 구현이 집중됨. 병렬 수정 전 화면/상태 경계 분리 필요.
- localStorage 복원 시 JSON.parse 이후 데이터 구조 검증이 없음. 손상 데이터에 대한 방어 필요.
- 최대 10MB 파일은 data URL 저장 시 브라우저 저장 한도를 초과할 수 있음. 현재 실패 알림만 제공.
- 저장 실패 후 결과 링크가 이전 저장 결과를 복원할 수 있음. 저장 성공 여부와 링크 제공의 일관성 검증 필요.
- 일부 화면 이동에서 playing/elapsed/menu 초기화가 누락될 수 있음. 재생 중 홈·샘플·복원 전환 점검 필요.
- 모바일 메뉴 aria-expanded, 카드 선택 상태 전달, 단계 이동 시 초점 관리 보완 필요.
- 실제 영상/음성/서버 공유/관리자 인증 없음: 현재 범위상 의도된 미구현.
- 아키텍처 import 경계 자동 검사 및 브라우저 E2E 자동화는 미구현.

## 검증 기록
- 이전 UI 구현: build/typecheck 통과, 좁은 브라우저 화면과 기본 선택→제작→결과 흐름 수동 확인. 모든 업로드/복원 경계 조건을 검증한 것은 아님.
- 하네스 초기 설정: 실행 결과는 `docs/plans/harness-bootstrap.md`에 기록.
